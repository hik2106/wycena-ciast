# Wycena Ciast

Prosta aplikacja na telefon (PWA) do wyceny domowych ciast: koszt składników, pracy i prądu,
zysk i marża, przeliczanie przepisu na inną porcję.

Aplikacja: https://hik2106.github.io/wycena-ciast/

- Działa w przeglądarce telefonu; po dodaniu do ekranu początkowego działa jak aplikacja i bez internetu.
- Wszystkie dane zostają w telefonie – nic nie jest wysyłane na serwer. Kopię zapasową zapisuje się jako plik.
- Bez frameworków i zależności: HTML, CSS, JavaScript.
